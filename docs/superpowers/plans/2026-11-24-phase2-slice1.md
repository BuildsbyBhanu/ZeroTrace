## Task 1: Fix Windows CLI Encoding (`cli/main.py`)

### Problem
The CLI output garbles on Windows consoles due to CP1252 encoding issues with Unicode characters (checkmarks, badges).

### Solution
- Set `encoding="utf-8"` in Console initialization
- Use ASCII alternatives when UTF-8 fails
- Force UTF-8 mode for the process

### Files to Modify
- `cli/main.py`
